    Agents¶

    Every agent but TDMPC2MultiTask subclasses ActorCritic. Its constructor takes the environment, the algorithm's own hyperparameters and extensions=(); train runs one or more seeds at once. TDMPC2MultiTask learns offline from a dataset and keeps its own train, with the same seeds-at-once call.

    Each agent's reference, with every constructor argument, is at the end of its algorithm page, next to the paper it follows and the notes on using it:

    Initialize the agent.

    Parameters:

    Name Type Description Default
    actor_learning_rate float | Callable[[int], float]

    Learning rate for the actor's optimizer, or its schedule.

    		 0.0003
    critic_learning_rate float | Callable[[int], float]

    Learning rate for the critic's optimizer, or its schedule.

    		 0.0003
    weight_decay float

    decoupled weight decay of the actor's and the critic's optimizers (OptimizerConfig.weight_decay): on top of the Adam step, each step multiplies their parameters by 1 - lr * weight_decay. It reaches the networks only: a scalar dual variable (SAC's temperature) keeps its own plain Adam. 0 keeps plain Adam.

    		 0.0
    memory Optional[Union[MemoryConfig, dict]]

    Pluggable memory block (MemoryConfig or its dict form); None keeps the networks feedforward.

    		 None
    normalize_rewards bool

    divide the rewards the agent learns from by a running standard deviation (logged returns stay in the env's units). By default the single-step reward's.

    		 False
    reward_normalization_gamma Optional[float]

    with normalize_rewards, divide by the running standard deviation of the discounted return with this discount instead, as SB3's VecNormalize (gamma) and gymnasium's NormalizeReward do.

    		 None
    action_repeat int

    simulator steps per agent step on brax / playground envs (episode_length then counts simulator steps); stored on env_args. gymnax envs and prebuilt envs support only 1.

    		 1

    resume_iteration_offset ¶

    resume_iteration_offset(initial_state)

    Absolute index of the first scan iteration when resuming.

    train feeds it to the inner train function so a resumed run sees absolute iteration indices (see build_resumable_train). The default 0 restarts the indices at every train call (every existing agent; APG's per-stage cadence relies on it). Agents whose schedules are functions of the absolute tick override this to return their tick counter -- a host-side int, equal across seeds.

    Train the agent, every seed at once.

    Parameters:

    Name Type Description Default
    n_timesteps int

    Timesteps this call trains for.

    		 int(1000000.0)
    num_episode_test int

    Number of episodes for evaluation during training.

    		 10
    initial_state Optional[BaseAgentState]

    a state (or (state, out)) train returned, to resume from: the run continues from its timestep.

    		 None
    total_timesteps Optional[int]

    the whole run's horizon, which every schedule (training fraction, extensions, exploration, the logging's end) runs over; None: this call's end, its start (0, or the resumed timestep) plus n_timesteps. Pass the same horizon to every call of a run split into calls to follow the schedules of one call.

    		 None

    Returns (state, out), each leaf with a leading seed axis. On the shared loop (ajax.agents.loop) out is None without a logging config, else the evaluations.

    train_offline ¶

    train_offline(
    dataset,
    n_updates,
    seed=42,
    num_episode_test=10,
    logging_config=None,
    on_ids_ready=None,
)

    Train on a transition dataset alone, with no environment step.

    n_updates of the agent's own update on a replay holding dataset's rows (:meth:ajax.agents.loop.TrainLoop.offline), evaluating every logging_config.log_frequency updates. Returns (state, out) as :meth:train does, with the state's timestep and evaluation count back at 0, so that train(initial_state=state, ...) fine-tunes online from it, its replay keeping the dataset's rows (with learning_starts=0, from the first step).

    Raises ValueError on an agent without a transition replay.
